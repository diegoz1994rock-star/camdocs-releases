# CAM DOCS — descargas

**Every document. Smarter.** Escáner de documentos **gratuito** para **Android**, de **ASTRIM**.

Escanea con tu teléfono y obtén documentos rectos, limpios y con texto que puedes buscar: detección automática de bordes, 8 filtros, reconocimiento de texto en el dispositivo, selección del texto directamente sobre la imagen, traductor a 17 idiomas, PDF con texto buscable y ASTRIM Intelligence para resumir documentos y extraer los datos de facturas y contratos. Sin cuenta, sin marca de agua y sin publicidad.

👉 Más información: <https://astrim-web.web.app/productos/cam-docs>

## Descargar

Ve a [**Releases**](../../releases/latest) y descarga:

| Archivo | Para |
|---|---|
| `CamDocs_1.0.0_Android_arm64.apk` | **Recomendada.** Casi todos los teléfonos Android de los últimos años (64 bits) |
| `CamDocs_1.0.0_Android_armv7.apk` | Teléfonos antiguos con procesador de 32 bits |

**Requisitos:** Android 7.0 o superior.

**Instalación:** abre la APK desde el teléfono. Android pedirá permitir «Instalar apps desconocidas» para tu navegador o gestor de archivos.
